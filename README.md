# youremailvalidationsucks.com

Static GitHub Pages site for explaining why email validation often breaks on newer TLDs and showing practical regex examples for modern applications.

## Local preview

Because the site is plain static HTML, you can preview it locally with any simple web server, for example:

```bash
python3 -m http.server --directory /home/runner/work/youremailvalidationsucks.com/youremailvalidationsucks.com 8000
```

Then open <http://localhost:8000>.
